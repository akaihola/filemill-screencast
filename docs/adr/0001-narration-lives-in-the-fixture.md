# Narration lives in the fixture, not in captions

The screencast has no captions or text overlays. All text a viewer reads comes
from fixture folder names, file names and file contents: a name says what to do
to reach it, and the preview says why it helps. An overlay would be easier to
write. Content-as-narration was chosen because it keeps every frame a real
Filemill screen, and because the text then shows Filemill doing the very thing
it describes. Do not add captions to fix unclear narration; rename or rewrite
the fixture.
